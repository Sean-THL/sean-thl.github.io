Project · Manipulation

5-DoF Robotics Arm Perception and Control

RGB-D block detection, camera calibration and kinematics for semi-autonomous pick-and-place.

Project overview

This project connects computer vision with the motion of a 5-DoF robotic arm for semi-autonomous pick-and-place. An Intel RealSense RGB-D camera observes colored blocks in the workspace, while a Python pipeline combines visual detections, coordinate transformations and kinematic reasoning to identify reachable targets.

Intrinsic camera calibration relates image measurements to camera geometry, and extrinsic calibration aligns the camera with the robot coordinate frame. This alignment allows detected block locations to be interpreted in the same coordinate system used to command the arm.

OpenCV-based block detection identifies objects in the camera view. Product-of-exponentials kinematics describes the relationship between the arm’s joint configuration and end-effector pose, connecting the perception pipeline with physical manipulation.

The implementation brings together sensing, calibration and arm execution in a single workflow. The resume reports an average positional error of 1.9% for the project.
