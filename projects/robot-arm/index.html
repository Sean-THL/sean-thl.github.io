Project · Manipulation

5-DoF Robotics Arm Perception and Control

RGB-D block detection, camera calibration and kinematics for semi-autonomous pick-and-place.

Research question

How can calibrated RGB-D perception and robot kinematics support reliable semi-autonomous pick-and-place with a 5-DoF arm?

My contribution

  • Built an OpenCV perception pipeline for colored-block detection using an Intel RealSense RGB-D camera.
  • Performed intrinsic and extrinsic calibration to transform image measurements into the robot coordinate frame.
  • Connected product-of-exponentials kinematics, target selection, and arm execution in one workflow.

Results & current status

The integrated system achieved an average positional error of 1.9% in the project evaluation.
