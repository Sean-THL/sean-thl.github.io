SE(3) Geometric Control for Lissajous Trajectory Tracking

Simulating SE(3) geometric control for Crazyflie Lissajous trajectory tracking.

Project overview

This project develops and simulates a geometric controller on SE(3) for a Crazyflie quadrotor to track a Lissajous reference trajectory.

The workflow uses Gazebo to visualize the quadrotor simulation alongside coordinate-frame and pose visualization. It focuses on connecting position and attitude control with a three-dimensional reference path while respecting the coupled translational and rotational dynamics of the aerial platform.

The supplied material demonstrates the simulation setup; quantitative tracking-error or hardware-deployment results are not claimed.
